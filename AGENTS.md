# House Expenses Tracker — Agent Guide

## TL;DR
```bash
pip install -r requirements.txt   # install flask
python3 main.py                   # run web server — sign up via browser
python3 main.py --port 8080       # custom port
python3 main.py --host 127.0.0.1  # custom host
```

Open browser at `http://localhost:5000` (port set in `config/settings.py`).

## Architecture

| File | Role |
|---|---|
| `main.py` | Flask entrypoint — app creation, secret key, CLI args (`--host`, `--port`, `--debug`) |
| `routes.py` | All routes, decorators, permission helpers, context processor (`register_routes(app)`) |
| `config/settings.py` | Constants: `PORT`, `MONTHS_INDEX`, attribute lists, `USER_DB_DIR`, `USERS_DB` |
| `db/sql_manager.py` | `SQLManager` class + `generate_user_db_sql()` — SQLite data access layer |
| `db/init.sql` | Legacy per-user DB schema (default attributes) |
| `utils.py` | Helpers: `parse_date_bound`, `get_color_for_attribute` |
| `init_app.py` | Initialization — creates dirs, `users.db`, `flask_secret.key` |
| `templates/` | Jinja2 HTML templates (one per feature) |
| `static/css/style.css` | CSS |

## Key facts

- **Language**: Italian — month names (`GENNAIO`, `FEBBRAIO`, …), all UI strings. Keep it consistent.
- **DB**: SQLite only. Flask is the only external dependency.
- **Auth**: Multi-user via `users.db` (central) + per-user SQLite DB in `data/user_data/`. Signup creates a fresh DB with custom attributes via `generate_user_db_sql()`. Login sets `session['db_path']`.
- **Port**: Set via `config/settings.py:PORT` (default `5000`). CLI override: `--port`.
- **Secret key**: Persisted in `flask_secret.key` so sessions survive server restarts.
- **Computed columns**: `uscite_variabili`, `uscite_fisse`, `uscite_totali`, `delta` are maintained by SQLite triggers (generated by `generate_user_db_sql()`). Do not touch them from Python.
- **Year**: Stored in Flask session (`session['year']`). Defaults to current year on first visit. Change via `/change-year`.

## Gotchas

- `db/init.sql` is **out of sync** with `generate_user_db_sql()` — it has hardcoded default attributes. New users get dynamic SQL. `init.sql` is legacy only.
- `push_db.sh` and `test.sh` are local-only scripts, gitignored, not part of the project workflow.
- No tests, no CI, no linter, no formatter.

## Conventions

- All SQL queries use **parameterized `?` placeholders** — never interpolate values directly. Dynamic column names are validated against actual DB columns via PRAGMA.
- Month format in DB: `YYYY_MESE` (e.g. `2026_GENNAIO`).
- Routes are defined inside `register_routes(app)` in `routes.py`. Each page handles both display (GET) and action (POST) — results render on the same page.
- New features: add route in `routes.py`, create template in `templates/`.
